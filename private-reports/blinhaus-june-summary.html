План июля — три приоритета

1. Stripe высокий импакт
  1. 7loc → Налаштування → Оплати → Stripe → подключить карточку компании
  2. Stripe верификация: 1–2 рабочих дня
  3. После запуска: тестовый заказ → убедиться что пиксель фиксирует purchase
  4. Прогноз: конверсия корзина→заказ с 5% → 15–20%, выручка сайта ×3
2. Telegram-алерты на новые заказы 15 минут
  1. Railway → Variables → TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID → сохранить
  2. Бот уже поддерживает алерты — только переменные пустые
  3. Результат: каждый Messenger-заказ → мгновенное уведомление на кухню
3. UTM к рекламе тортов → увидеть конверсию 30 минут
  1. Кампания тортов уже правильно ведёт в Messenger — 117 диалогов/нед по 0,45 €/лид.
  2. Добавить UTM-параметр в объявление → бот передаёт его в заказ → видим сколько тортов продала реклама.
  3. Потенциал: часть из 328 € Messenger-продаж периода — это торты из этой кампании.
